# Портфолио AI-инженера — Дизайн-система

## Обзор

Эта дизайн-система поддерживает персональный веб-сайт портфолио для AI-инженера. Продукт — это одностраничный или многостраничный сайт, представляющий профессиональную работу, проекты, статьи и контактную информацию. Эстетика намеренно минималистична, техническая и точная — основана на логике кода/терминала, а не на типичном языке дизайна «творческого агентства».

**Исходные материалы:** Не предоставлены (создано на основе описания: "портфолио AI-инженера, простой и чистый дизайн, шрифт Consolas")

## ОСНОВЫ КОНТЕНТА

### Голос и тон
- **Прямолинейно.** Без лишних фраз вроде «Я увлечён...» или «Я специализируюсь на...». Просто скажи суть.
- **Технически, но доступно.** Пишите для умного généralisте, не только для инженеров. Избегайте жаргона без необходимости.
- **От первого лица («я»).** Это персональный сайт; берите ответственность.
- **Нижний регистр по умолчанию.** Меню, заголовки навигации и подписи UI часто в нижнем регистре (например, «обо мне», «проекты», «контакты»). Основные заголовки используют sentence case, не Title Case.
- **Без эмодзи.** Дизайн не использует эмодзи — это бы конфликтовало с терминальной эстетикой.
- **Даты и метаданные** используют формат, близкий к ISO (например, «2024», «янв 2024») а не многословные формы.

### Примеры текста
- Навигация: `обо мне`, `проекты`, `статьи`, `контакты`
- Призыв к действию: `посмотреть проект →`, `читать дальше →`, `связаться со мной`
- Заголовок раздела: «Несколько вещей, которые я недавно создал.» (не «Вот несколько захватывающих проектов!»)
- Биография: «Я создаю системы на пересечении языковых моделей и инженерии программного обеспечения.»

## ВИЗУАЛЬНЫЕ ОСНОВЫ

### Цвета
Компактная 2-режимная (светлая/тёмная) палитра. Без цветных всплесков, без градиентов.

| Токен | Светлая | Тёмная | Применение |
|---|---|---|---|
| `--bg` | `#FAFAF9` | `#111110` | Фон страницы |
| `--bg-2` | `#F2F2F0` | `#1C1C1B` | Тонкая поверхность (карточки, код) |
| `--bg-3` | `#E8E8E6` | `#282826` | Состояния при наведении, границы |
| `--fg` | `#111110` | `#F0F0EE` | Основной текст |
| `--fg-2` | `#6B6B69` | `#8A8A88` | Вторичный текст / метки |
| `--fg-3` | `#ABABAA` | `#555554` | Placeholder / отключено |
| `--border` | `#E2E2E0` | `#2A2A28` | Разделители и границы |
| `--accent` | `#1C64F2` | `#3B82F6` | Ссылки, выделение, focus rings |
| `--accent-subtle` | `#EFF6FF` | `#1E3A5F` | Фоны с акцентом |
| `--green` | `#059669` | `#34D399` | Терминальный зелёный, «успех» |

### Типография
- **Семейство шрифтов**: Consolas → **JetBrains Mono** (заменитель с Google Fonts — см. примечание ниже)
- **Система с одним шрифтом**: один шрифт для всего; иерархия выражается через размер, вес и цвет — не через смешивание шрифтов.
- **Масштаб** (rem-основанный, корень 16px):

| Токен | Размер | Вес | Применение |
|---|---|---|---|
| `--text-xl` | 2.5rem (40px) | 500 | Заголовок страницы / hero |
| `--text-lg` | 1.5rem (24px) | 500 | Заголовки секций |
| `--text-md` | 1.125rem (18px) | 400 | Подзаголовки, выделение |
| `--text-base` | 1rem (16px) | 400 | Основной текст |
| `--text-sm` | 0.875rem (14px) | 400 | Метки, метаданные |
| `--text-xs` | 0.75rem (12px) | 400 | Подписи, сноски |

- **Межстрочный интервал**: 1.6 для основного текста; 1.2 для заголовков
- **Межбуквенный интервал**: −0.01em для заголовков; 0 для основного текста

### Отступы
8px базовая единица. Масштаб: 4, 8, 12, 16, 24, 32, 48, 64, 96, 128px.

### Фоны
- **Без градиентов.** Только плоский цвет.
- **Без фоновых изображений** на главном сайте.
- Блоки кода и встроенный код используют `--bg-2` с границей 1px `--border`.
- Секции страницы разделены тонкими линиями `--border`, а не затемнением.

### Границы и скругления
- **Граница**: 1px solid `--border`; без двойных границ
- **Скругление**: очень маленькое — `2px` для маленьких элементов (теги, бейджи); `4px` для карточек/инпутов; `0` тоже допустимо и используется для жёсткого терминального вида.

### Тени
- В основном **нет теней**. Эстетика плоская.
- Одна опциональная тонкая тень для плавающих элементов (подсказки, выпадающие меню): `0 4px 12px rgba(0,0,0,0.08)`.

### Анимация
- **Минимальная.** Переходы только для `color`, `background-color`, `opacity`, `border-color`.
- Продолжительность: `150ms`; функция времени: `ease`.
- Без отскоков, без spring-физики, без входящих анимаций для контента.
- Ссылки и кнопки: только переходы `color` и `opacity`.

### Состояния при наведении / Нажатие
- Ссылки: `--fg` (не подчёркивание по умолчанию; подчёркивание при наведении)
- Кнопки: `background-color` темнеет (или светлеет в тёмном режиме) на один шаг
- Теги/чипсы: `background-color` → `--bg-3`
- Нажатие: лёгкое `opacity: 0.8` — без трансформаций масштаба

### Карточки
- Плоский прямоугольник; `background: --bg-2`; `border: 1px solid --border`; `border-radius: 4px`; без тени.
- Внутренние отступы: `24px`
- Наведение: цвет границы переходит на `--fg-3`

### Layout
- Максимальная ширина контента: `720px` для текста; `960px` для полного layout
- Однолонный по умолчанию; двухколонная сетка проектов на широких экранах
- Навигация: минимальный верхний бар, имя слева + ссылки справа; не sticky по умолчанию

### Иконография — краткая сводка
Нет библиотеки иконок. Unicode стрелки (`→`, `↗`, `←`) и минимальный SVG используются по необходимости. См. раздел ИКОНОГРАФИЯ.

### Цветовая палитра изображений
- Если используется фотография: приглушённая/мuted, без тёплых фильтров stock фото.
- Скриншоты кода предпочтительнее декоративных изображений.

## ИКОНОГРАФИЯ

Нет специализированной системы иконок. Портфолио использует:
- **Unicode стрелки**: `→` (навигация), `↗` (внешняя ссылка), `←` (назад)
- **Минимальный встроенный SVG** для конкретных случаев (например, логотипы GitHub/соцсетей)
- **Нет иконочного шрифта**, нет Lucide/Heroicons, нет эмодзи-иконок

Иконки соцсетей (GitHub, LinkedIn и т.д.) рисуются как простые SVG размером 16–20px в цвете `--fg-2`, переходящие на `--fg` при наведении.

## Примечание о шрифте

**Consolas** — это собственный шрифт Microsoft, недоступный на Google Fonts. Эта дизайн-система использует **JetBrains Mono** как практически идентичный заменитель (та же монопространная эстетика, похожие метрики, open source). Если у вас есть лицензия Consolas и вы хотите его встроить, поместите `Consolas.woff2` в папку `fonts/` и обновите правило `@font-face` в `colors_and_type.css`.
