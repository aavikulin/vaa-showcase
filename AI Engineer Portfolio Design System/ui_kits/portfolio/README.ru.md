# UI Kit - Сайт-портфолио

## Обзор //vaa
Высокодетализированный кликабельный прототип сайта-портфолио AI-инженера. Четыре страницы: обо мне, проекты, статьи, контакты. Построен на React + JetBrains Mono.

## Компоненты

| Компонент | Описание |
|---|---|
| `Nav` | Верхняя панель навигации с именем/курсором и ссылками. Свойства: `name`, `links`, `active`, `onNav` |
| `Tag` | Небольшой чип. Варианты: `default`, `accent`, `green`, `dark` |
| `Button` | Кнопка призыва к действию. Варианты: `primary`, `secondary`, `ghost`. Размеры: `md`, `sm` |
| `ProjectCard` | Карточка проекта с названием, годом, описанием, тегами и ссылкой |
| `WritingRow` | Строка статьи в блоге с заголовком, датой, временем чтения и тегами |
| `Section` | Секция страницы с меткой в верхнем регистре и дочерними элементами |
| `ContactForm` | Форма с email и сообщением, включая состояние после отправки |
| `Footer` | Нижняя панель с копирайтом и иконками соцсетей |

## Использование

```html
<!-- Подключите компоненты -->
<script type="text/babel" src="Components.jsx"></script>

<!-- Используйте в приложении -->
<Nav name="ваше имя" active="work" onNav={setPage}/>
<ProjectCard title="Мой проект" year="2024" description="..." tags={["python"]}/>
```

## Ширина макета
Макет шириной 960px, максимальная ширина текстового блока 720px, боковые отступы 48px.
